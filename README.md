# 🛒 BlinkIT Grocery Sales Analysis Dashboard

An interactive **Excel dashboard** analyzing BlinkIT's grocery sales data to uncover trends in item performance, outlet performance, and customer preferences — built to help stakeholders make faster, data-driven decisions.

## 📌 Project Overview

BlinkIT (formerly Grofers) is one of India's largest online grocery delivery platforms. This project analyzes item-level and outlet-level sales data to answer key business questions:

- Which product categories and fat-content segments drive the most sales?
- How does outlet type, size, and location tier affect performance?
- Does the age of an outlet influence its sales?
- What does overall customer satisfaction (ratings) look like across the business?

The entire workflow — data cleaning, DAX-style calculated metrics, pivot tables, and an interactive dashboard with slicers — was built natively in **Microsoft Excel**.

## 🧾 Dataset Description

The dataset contains **8,523 item-outlet records** across **10 outlets** and **16 product categories**.

| Column | Description |
|---|---|
| Item Identifier | Unique product code |
| Item Fat Content | Regular / Low Fat classification |
| Item Type | Product category (e.g., Snack Foods, Dairy, Household) |
| Item Weight | Weight of the product |
| Item Visibility | % of total display area allocated to the product in-store |
| Outlet Identifier | Unique store code |
| Outlet Establishment Year | Year the outlet was opened |
| Outlet Size | Small / Medium / High |
| Outlet Location Type | Tier 1 / Tier 2 / Tier 3 city |
| Outlet Type | Grocery Store / Supermarket Type1 / Type2 / Type3 |
| Sales | Revenue generated by the item at that outlet |
| Rating | Customer rating for the item |

---

## 🎯 Objective

To build a single-page Excel dashboard that lets a business user filter by **outlet type, location, and outlet size**, and instantly see how sales, ratings, and category performance shift — replacing static reports with an interactive, self-serve view.

---

## 🛠️ Tools & Techniques Used

- **Microsoft Excel** — data cleaning & standardization (fixing inconsistent labels like `Low Fat` / `low fat` / `Regular`)
- **Pivot Tables & Pivot Charts** — aggregating sales by category, outlet, and location
- **Slicers** — interactive filtering by Outlet Type, Location Tier, and Outlet Size
- **Formulas** — `SUMIFS`, `AVERAGEIFS`, `COUNTIFS` for KPI calculations
- **Conditional Formatting** — highlighting top/bottom performers
- **Chart types used** — bar, column, donut/pie, and line charts for trend analysis

## 💡 Key Insights

1. **Low Fat items outsell Regular items** — Low Fat products contribute roughly **63%** of total sales, more than 1.7x Regular items, suggesting a strong customer lean toward healthier options (once the `low fat`/`Low Fat` label inconsistency is standardized).

2. **Fruits & Vegetables and Snack Foods are the top-selling categories**, together contributing close to **30%** of total sales, while **Seafood, Breakfast, and Starchy Foods** are the lowest-performing categories.

3. **Supermarket Type1 dominates revenue**, generating nearly **66%** of total sales despite not being the largest format by outlet size — indicating this format converts foot traffic most efficiently.

4. **Tier 3 cities outperform Tier 1 and Tier 2** in total sales, showing that BlinkIT's growth isn't limited to metro areas — smaller cities are a meaningful revenue driver.

5. **Medium-sized outlets generate the highest sales**, followed by Small and then High — outlet size doesn't scale linearly with performance, hinting that operational efficiency matters more than sheer size.

6. **Outlets established in 2018 recorded the highest sales** among all vintages, while the single outlet from **2011 (OUT010) lags significantly behind every other outlet** — worth investigating for underperformance (it's also a Grocery Store format, not a Supermarket).

7. **Customer ratings are consistently high and stable** (average ~3.97/5) across nearly all categories and outlets, suggesting satisfaction issues are not a major driver of the sales gaps seen above — the differences are more likely tied to format, location, and assortment.
